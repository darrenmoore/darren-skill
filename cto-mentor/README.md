# cto-mentor

A sparring partner for technical founders: argues the other side, turns gut calls into numbers, asks the questions you skipped.

Type: skill

## Files
- `SKILL.md`: the skill, with six modes (challenge, receipt, interview, prep, nudge, capture) and the rules for keeping a context record honest.
- `context-template.md`: the context file you fill in (company, stage, partners, commitments, current bets).

## Adopt it
Paste this into your agent:

> Read cto-mentor at https://github.com/darrenmoore/darren-skill/tree/main/cto-mentor. It was written for someone else's project, so don't install it as it is. Read every file in it, then look at how this project works: our skills, hooks, conventions and the way we ship. Tell me whether it fits, what it overlaps with, and how you would adapt it to this project: what to keep, what to change and what to drop. Wait for me to decide before you add anything.

Needs a folder for the context files and read access to wherever your live numbers sit (CRM, tracker, analytics).
