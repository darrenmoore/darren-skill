# cto-mentor

A sparring partner for technical founders: argues the other side, turns gut calls into numbers, asks the questions you skipped.

Type: skill

## Files
- `SKILL.md`: the skill, with six modes (challenge, receipt, interview, prep, nudge, capture) and the rules for keeping a context record honest.
- `context-template.md`: the context file you fill in (company, stage, partners, commitments, current bets).
