# Work ledger

The parent folder is the status: `_next`, `_active`, `_parked` or `_done`.

A work item is a folder with a stable, flat kebab-case slug, a `README.md` brief, numbered task
files and a `PROGRESS.md` when needed. Numbers are execution order.

Move the whole item to change status. Keep one or two items active. Superseded or abandoned work
goes to `_done` with a line saying so, rather than being deleted.

Repository evidence outranks stale progress notes.
