# tone

Writes in your voice from a voice file, with notes on how to build that file.

Type: skill

## Files
- `SKILL.md`: the routing: read the voice file, name the audience, draft, run the check list, and record corrections as before/after pairs.
- `voice-template.md`: how to build your voice file from real samples (constants versus dials, audiences, before/after pairs, a check list), plus a skeleton to copy.
