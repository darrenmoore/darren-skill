# Before and after

Real sentences an agent wrote, next to the version you accepted or wrote yourself. Examples teach voice and clarity better than bans do, so the writing agent reads the most recent ten before drafting.

Add a pair whenever you rewrite or reject a sentence and the fix is a better version, not only "never say X". A ban tells the writer what to avoid, and avoiding things tends to produce clipped phrasing. A pair shows what to write instead.

Newest first. Keep the surface and the piece so the context can be found again:

```
- **Before:** "<what the agent wrote>"
  **After:** "<what you accepted>"
  **Why:** <one line: unclear, overclaimed, wrong voice, invented, compressed>
  *(<surface, e.g. blog post or release note>, <piece>, <YYYY-MM-DD>)*
```
